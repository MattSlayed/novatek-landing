# NOVATEK landing page

Landing page design work for NOVATEK LLC, published with GitHub Pages from `main` by `.github/workflows/pages.yml` (set the repository's Pages source to "GitHub Actions").

```bash
npm install
npm run dev      # work on it
npm run build    # type-check and build dist/
npm run preview  # serve dist/ at http://localhost:4173/novatek-landing/
```

Vite + React + TypeScript, Tailwind v4 and shadcn/ui. Copy and facts live in `src/content.ts`, pictures and their credits in `src/pictures.ts`.

The pictures in `public/pictures/` are public domain (CC0) from The Metropolitan Museum of Art's Open Access collection and are credited on the page.

The fonts are under the SIL Open Font License (`fonts/OFL.txt`). The skills in `.claude/skills/` keep their own licences: impeccable is Apache 2.0 and taste is MIT.
