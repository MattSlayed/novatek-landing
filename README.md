# NOVATEK landing page

Landing page design work for NOVATEK LLC, published with GitHub Pages from `main` by `.github/workflows/pages.yml` (set the repository's Pages source to "GitHub Actions"). This branch holds "Future Past", a brand-free page built from Matthew's thesis brief.

```bash
npm install
npm run dev      # work on it
npm run build    # type-check and build dist/
npm run preview  # serve dist/ at http://localhost:4173/novatek-landing/
```

Copy lives in `src/content.ts`, pictures and their credits in `src/pictures.ts`. The pictures are public domain (CC0) from The Metropolitan Museum of Art and are credited on the page. Fonts are self-hosted under `public/fonts/` (SIL OFL, see `OFL.txt` there).

The fonts are under the SIL Open Font License (`fonts/OFL.txt`). The skills in `.claude/skills/` keep their own licences: impeccable is Apache 2.0 and taste is MIT.
